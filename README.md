# Nithilan Saravanan — Portfolio

Personal portfolio site, single-page HTML/CSS, hosted on GitHub Pages.

🔗 **Live:** https://nithilan0710.github.io/portfolio/

## Sections

- Home / Hero
- About
- Skills
- Resume (Experience & Education)
- Projects
- Patents & Publications
- Awards & Leadership
- Contact

## Tech

- Pure HTML + CSS (no frameworks, no build step)
- Fonts: Space Grotesk, Lora, JetBrains Mono (Google Fonts)
- Fixed bottom navigation with scroll-based active state (vanilla JS)

## Run locally

Just open `index.html` in a browser — no install needed.

## Deploy (GitHub Pages)

1. Push `index.html` to a repo named `portfolio` (any name works for project sites; only `<username>.github.io` repos serve from the root domain)
2. Enable GitHub Pages in repo settings (branch: `main`, root)
3. Site goes live at `https://nithilan0710.github.io/portfolio/`

## Customize

- Replace placeholder photo: edit `src` in the `.hero-photo img` tag
- Update contact/social links in the hero and contact sections
- Colors/fonts controlled via CSS variables in `:root`
